# FlowKit 工具工作台

靈感來自 [CorentinTh/it-tools](https://github.com/CorentinTh/it-tools)，2026-11-14 查詢 GitHub API 為 41,261 stars。此作品為獨立撰寫，未複製上游程式碼或品牌資產。

## 使用

直接以瀏覽器開啟 `dist/index.html`。SHA-256 與剪貼簿功能建議使用 HTTPS 或 localhost。

11 個工具支援 JSON 格式化、壓縮、欄位遮罩、UTF-8 Base64、URL 編解碼、逐行去重、排序、清理空白與 SHA-256。可組合步驟、調整順序、查看中間結果、匯入文字檔、匯出結果、儲存流程。所有資料處理在瀏覽器執行，不含 API 或雲端同步。

新增價值：跨工具流程、自動辨識輸入、可重用流程範本、預設不持久儲存輸入。遮罩採用欄位名稱規則，不能涵蓋任意文字內的所有敏感資料。

## 限制

這是可用的精簡版本，沒有多人協作、帳號系統或上游的完整工具集合。瀏覽器資料僅存在同一裝置及來源下；大型資料處理可能佔用主執行緒。
